In dit project hebben we een model ontwikkeld op basis van een dataset van ProRail, waarmee voorspeld wordt hoe lang het zal duren voordat treinen weer rijden na een storing. In deze repository laten we stap voor stap zien hoe dit model tot stand is gekomen.

Eerst hebben we een model gemaakt met slechts drie kenmerken (features) en vervolgens met zes kenmerken. Dit stelde ons in staat om het gedrag van het model beter te begrijpen en heeft ons voorbereid op het werken met het uiteindelijke model met alle gekozen kenmerken.

We raden aan om de repository in de aangegeven volgorde door te nemen voor een goed begrip van ons proces en de gemaakte keuzes.
